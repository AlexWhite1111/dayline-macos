# 今日 App

双击“今日.app”即可启动。它不会显示在 Dock 中，会以悬浮胶囊的形式停靠在屏幕边缘。

- 点击加号并输入待办；按 Return 或点击其他区域保存。
- 拖动待办胶囊调整时间；拖动会按 15 分钟吸附。
- 点击时间可选择当天时间。
- 点击圆圈完成，内容会淡化并添加删除线。
- 点击边缘圆点收起或展开；拖动圆点可改变高度并自动贴到左右边缘。
- 双击时间轴可显示或隐藏三个控制按钮。
- 设置可调整宋体字号、时间轴高度和当天时间范围。

当天内容会自动保存，重启 App 不会丢失。跨过设定的当天结束时间后自动清空，不保存历史。

退出方法：打开右下角设置，选择“退出今日”，或按 Command + Q。
